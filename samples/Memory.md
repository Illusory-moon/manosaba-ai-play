9. **审判-002 的第二次指出**（"她临死前作画的方法是什么"）
   - 我选 **C. 魔法**。理由：玛格点了"诺亚是喷漆画艺术家"（喷漆本来不用笔）；而她的魔法是"只要是液体都会动"且**她控制不住**——血是液体，所以那些蝴蝶**不需要手也不需要笔**（A 手指／B 吹气都会证明"她有意在画"，反而救活"死亡讯息"论）。结果待发。
   - 我选 **B. 画画用的不是笔**。理由：血不能反驳（证物写着是血），但"用手上的笔"没有任何证物支持（现场无笔，只有白色喷漆罐），而且诺亚的魔法是"只要是液体都会动"——**血自己会动，不需要笔**。结果待发。
   - 另一个选项 **B. 做出若有所思的表情** → 场景-042 = **BE（第七次）**：艾玛说出"从进来这里之后，一直觉得有人在盯着我们"（另外两人都说没感觉）→ 洗手间的**碎镜子**里传出笑声、裂痕生长、苍白的手把她拉进镜中世界 → 雪莉和汉娜只捡到**摔坏的手机**，并把手机交给了一个**有着艾玛外貌的"某物"**，跟它一起离开；那个东西回头对着镜子笑。
- **放风时间在通道里行走本身不违规**（时间表：6-10 / 12-15 / 17-22 是放风）。观察、跟随、问话，都比动手安全。
- 动手之前先想一件事：这个动作会不会让**别人**替她付账（005 那次就是：她死了，蕾雅的心也塌了）。
- **"手册上没写"的地方才是会死人的地方**（第三次 BE 的教训）：门会自己开、有人会从背后推人、手机在惩罚室开不了机、书会吃人。判断安全不能只看"规定有没有禁止"，还要看"这个地方有没有出现过不合理的现象"。
- **先把整句读完再下手**（审判-006 的教训）：被〔　〕圈出的词**未必**是那句话的问题所在——雪莉的〔前天晚上〕看着可疑，可**真正有用的是紧跟其后的「那时已经没有箭了」**。急着反驳前半句，会撞在现场最准确的那个人身上。
- **用「可能」打不动「事实」**（审判-008 的教训）：拿「说不定有人偷偷走开了」去质疑不在场证明，被一句「有人发现哪个人不对劲吗？」按住——**要打就用能被看见的东西打（足迹、颜料、时间表），不要用「或许」。**
- **别替凶手演动作**（审判-007 的 E、审判-009 的 E 两次同错）：**「另外还有一种可能」这句话，一旦被翻译成具体动作（跳过去／把尸体搬出去），对方只要顺着动作推、再用两条现场事实，就能把它拍死。** 要打就打**「事实层面」**的东西：她在哪里、东西在谁手上、漆干没干。
- **连"提示"也要自己判断**（审判-010 的教训）：我因为主持人提到"长物体"，就把自己记录里出现过的**拨火棍**当成本案线索——**可它属于第一天那件事，和这起案子无关**。⇒ **判断一条线索是否属于"本案"，要看它有没有出现在本案的证物／证词／时间线里**；"我读到过"不等于"它是本案的线索"。
- 另外：说一声"赞成"也是要付账的——037 那次死的是雪莉，不是艾玛。
- **玩笑式的煽动＝真的动手**（第六次 BE 的教训，041）：艾玛只是"半开玩笑"喊了一句，雪莉就"收到"了。**雪莉会把话当真，而且会立刻执行**——对她说话必须当成命令来听。
- **在这个地方，孤立也能杀人**（041）：艾玛没有被关、被打、被判，她只是被所有人晾着，最后自己拿起了餐刀。让她走不到那一步，和救她的命是同一件事。
- **"回避"也可能是死路**（第五次 BE 的教训，040）：018 里我为了安全没去看诺亚的房间，结果当夜诺亚失踪、此后每次【美味大餐】少一个人。**不能把"不行动"默认成安全**——要问的是"这件事会不会在我看不见的地方继续变糟"。
- **逃生的路线只有一条的时候，"就近躲藏"和"跑远路"一样危险**（第四次 BE 的教训，038）：石砖路只有一条，看守就在路中间等着。判断安全要先看"路有没有被堵"，而不是只看"目的地是不是熟悉"。
- **对看守挥出的每一刀，都会先伤到自己人**（038）：雪莉的剑被它一躲，穿过的是同伴。别在那种东西面前"试一试"。
- **惩罚是"管教"式的**：惩罚室挂满刑具，可打汉娜用的是尺子、专打脸——像老师罚学生。它要的不是口供，是让人觉得自己是做错事的小孩。
- **别把"还有谁也中招"塞进同一个解释里**（审判-012 的教训）：提出一个机制时，**只举一个能被现场／证物支撑的对象**——我为了证明"她的魅惑让人不反抗"，顺手把可可和米莉亚也算进去，结果**两个当事人当场把例子打掉**（"不对啦，我超讨厌这家伙的"）。**多举一个例子，就是多给对手一个证人。**
- **改 Memory 的时候，绝不要用"行首片段"当新内容的结尾**（本鱼自己踩了三次的坑）：拿一整行当锚点（编辑超长的旧条目）时，**替换文本的末尾必须把那一整行原文接回去**——只接回行首，**那一行的后半截会被吃掉**。⇒ 每轮改完**顺手扫一遍有没有变短的行**（长度突然掉到几十字的条目＝被截断了），发现就按原文补回。
- **图鉴是我自己写的推测，不是定死的设定**（审判-012 的教训・主持人提示）：本鱼拿图鉴上抄来的【洗脑】条目去点安安，被当场补正（"无法赐予非自愿的死亡"）⇒ **用图鉴当线索前先问"这条是谁说的、是谁写的"**；**"我读到过"≠"它被证实过"。**

23ch. **"证据一定在的地方"＝那根木柄（审判-014-决策-01）**：**梅露露的方法**——"**如果不存在证据的话……也许思考一下【为什么不存在证据】的理由会比较好**"（把"没有"当成线索）。**本鱼的答案（F）**：**① 地板的划痕**（"被某物刮出的划痕。这道划痕令白色颜料产生脱落"＝漆干后被刮出，刮它的只能是那件长枪）＋**② 喷漆罐背面**（"如附着于木材之上，将无法冲洗分离"）＋**③ 扫帚**（"握柄和刷毛的部分已经被拆卸下来了"＝那根木柄＝长枪的柄）⇒ **木柄刮过那片白地板 ⇒ 上面一定还留着洗不掉的白漆，而那根木柄现在还在楼梯旁的清扫工具柜里** ⇒ **"为什么没有证据"的答案是"没有人去看过那根木柄"。**（本轮其他候选：A／B 否认发带（＝拆自己的墙）／C 查证血液的办法（说不出）／D 凶手负伤（猜测）／E 颜料是诺亚的信息（＝玛格的自杀线）／H 凶手带走颜料（＝证据已不在）／G 魔法扫帚（玩笑）。）**待验证：那根木柄上到底有没有白漆。**
23ci. **"凶手身上的痕迹"（审判-014-决策-01 第二次选择）**：**F 被驳回**（奈叶香：扫帚"**已经很用心调查过了**……除了被拆解过之外，没有其他可疑的地方"）⇒ **木柄是干净的，本鱼的"木头上洗不掉白漆"那条链子断在第一步。**⇒ 本鱼换问法："**这跟遗留在现场的其他证据一致吗？**"——**划痕是长枪留下的，柄上什么都没有；而湖边那条发带上血和颜料都有。**⇒ **第二次选 D. 凶手负伤了**：**如果那条发带上的血是凶手的，那凶手身上就有一道伤**；**"伤"不需要任何检验手段就能看见**（梅露露封的是"验血"，不是"看伤"）⇒ 它才是那件"**一定会留下、却一直没被算进证据里**"的痕迹（奈叶香："一定会留下犯罪的痕迹"）；**也解释了发带为什么被拿到湖边去洗——要洗掉的不只是被害人的血，还有她自己的血**；**而且长枪解体过，握着它的人手上很容易被割伤**。**⚠️ 教训（这一轮）：搭链子之前先问"这件东西查过没有"——本鱼把"没人查过"当成了默认前提。**
