# 效果样本

这三份是**游玩 AI 自己写出来的记录**，用来展示这套流程实际跑起来是什么样。

| 文件 | 是什么 | 看点 |
|---|---|---|
| `体验-场景-004.md` | 正文场景：逐句体验（原文一句 + 此刻真实感想） | AI 会联想过往细节、怀疑视角、对角色有偏好和情绪 |
| `体验-审判-009-决策-01.md` | 魔女审判的决策文件 | AI 面对「点击台词里的关键字」时，会先划掉打不动的选项、再说明为什么挑这一个 |
| `Memory.md` | 记忆文件（上下文被压缩后给自己看的备忘） | 人物卡、时间线、谜团清单和「教训」都是 AI 自己整理的；图鉴速查一节已删 |

## 处理说明

- 为不重新发布原作文本，**逐句引用的原文已省略为「（第 N 句原文已省略）」**；
  主持人生成的提示（决策清单等）是自制内容，保留原样。
- `Memory.md` 额外删去了「魔女图鉴要点（速查）」一节（那一节基本是游戏内文档的转写）。
- 生成方式见仓库根的 `tools/strip-original.mjs`（只读原稿，输出到别处）：

```powershell
node tools\strip-original.mjs record\一周目\第01章\体验-场景-004.md samples
node tools\strip-original.mjs record\Memory.md samples --drop-section '## 9'
```

- **剧透警告**：三份样本都包含大量剧情剧透。
